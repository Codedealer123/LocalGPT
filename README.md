
# LocalGPT

[![MIT License](https://img.shields.io/badge/License-MIT-green.svg)](https://choosealicense.com/licenses/mit/)

A website that runs AI locally without needing any apps or other tools. This uses WebLLM and WebGPU letting it access near-native level speed while being easy to setup.
## Installation

Open [LocalGPT](https://cdgamez.xyz/localgpt) in your browser and go through the initial onboarding
## Requirements

- Firefox 145+
- Chrome/Edge 113+
- Safari 18+
- 1GB to 4GB VRAM depending on model
- Computer/Laptop recommended
## Features

- ChatGPT-like UI
- Easy onboarding
- Works on almost any device that supports WebGPU
